Agentic AI · LLMs that use tools

          
Agents that plan, call tools and check their work.

        

        

          

            
I build LLM agents that break a goal into steps, call tools such as SQL, search and code, and check the result before they answer. Then I measure them: my eval harness gates every release, and at Outlier and micro1 I rate agent replies against rubrics.

            
    
              
  • ƒ
    Tool use and function calling
    Typed tools for SQL, search, files and APIs, with validation and retries.
    • 
              
  • ↻
    Planning loops
    Plan, act, observe and repeat within a step budget, with memory between steps.
    • 
              
  • ⌕
    Retrieval (RAG)
    Grounding answers in documents and video: the video-search project finds the moment that matches a sentence.
    • 
              
  • ✓
    Evals and release gates
    A 60-task agent benchmark with bootstrap intervals and McNemar tests. Candidate v2: pass rate 80.0% → 95.0%, p = 0.0039.
    • 
              
  • ◎
    Guardrails and human review
    Rubric-based rating of LLM and agent replies in Hindi and English, with a written reason for each.
